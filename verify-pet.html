🔎 Verify it yourself

Every pet comes from a burn on Bitcoin. Nobody rolls the dice in secret: the pet is rolled from the hash of the block its burn landed in. This page shows that proof for any pet, and redoes the math in your browser. No wallet, nothing to sign.

    Run my own replay

    The site has no server deciding who owns what. Your browser reads every XCPETS burn from Counterparty and replays the game rules from the first block. The public pets.json feed is the same replay, run once an hour. This button replays every burn up to the file’s block here in your tab, then compares a SHA-256 of both.

    Not run yet. It takes a few seconds and downloads about 650 KB.

    Check it without this site

    1. Find the hatch burn on mempool.space or any Counterparty explorer, and the hash of the block it landed in.
    2. The seed is that block hash and the pet id joined by a colon, both lowercase. The DNA is the SHA-256 of the seed.
    3. The roll is plain JavaScript with no dependencies: js/pet-core.js (same seed, same pet). The game rules are js/v2-rules.js.
    4. To replay the whole game from a terminal, see the README (tools/replay-check.js).
