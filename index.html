XCPETS token

How it works

Seeded by BitcoinBlock hash + pet id → SHA-256 → sfc32 PRNG → traits → 32×32 pixels. Fully deterministic.
Four rarity tiersCommon 60% · Uncommon 27% · Rare 10% · Legendary 3%. Rarer tiers unlock rarer species, patterns and gear.
Six stagesEgg → Hatchling → Juvenile → Adult → Elder → Mythic. Each stage changes the expression and adds a gear rank.
Stacking gearSix slots: Headwear, Guise, Drip, Grip, Outfits, Footwear. Older, better-fed pets unlock more (1 up to 6; rarity no longer caps them), each species has one legendary signature hat (crowns are shared gear any pet can wear), and gear can be won or lost in battles and the weekly rumble (legendaries are always safe).
Burn XCPETS to playEvery extra costs XCPETS, and the tokens are burned for good. Burn to hatch a pet, then keep burning to feed it. Each burn grows it toward the next stage, and every new stage unlocks more gear.
The community petEveryone grows one shared pet together, and every burn helps it grow.
