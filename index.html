XCPETS

8-bit meme pets, rolled from Bitcoin blocks.

Twelve pixel meme characters: Pepe, Wojak, Chud, Bobo, Mumu, Snibby, Dodo, KEVIN, Peepo, Sarutobi, Doge and Lenny. Every pet is derived from a block hash (plus a pet id), so anyone can re-derive any pet and get exactly the same pixels.

How it works

Seeded by BitcoinBlock hash + pet id → SHA-256 → sfc32 PRNG → traits → 32×32 pixels. Fully deterministic.
Four rarity tiersCommon 60% · Uncommon 27% · Rare 10% · Legendary 3%. Rarer tiers unlock rarer species, patterns and gear.
Six stagesEgg → Hatchling → Juvenile → Adult → Elder → Mythic. Each stage changes the expression and adds a gear rank.
Stacking gearHeadband/scarf, armor, cape, weapon, crown. Tier caps the slots: Common 1, Uncommon 2, Rare 4, Legendary 5.
Burn XCPETS to playEvery extra costs XCPETS, and the tokens are burned for good. Burn to hatch a pet, then keep burning to feed it. Each burn grows it toward the next stage, and every new stage unlocks more gear.
The community pet: NakamotoEveryone grows one pet together. Every burn feeds it, and its name grows from Sat to Satoshi Nakamoto to the full title.
